# Tricky Towers PSP

Un homebrew per **PSP** che porta il gameplay di **Tricky Towers** sulla console portatile di Sony.  
Questo progetto è un **gioco homebrew per PSP** sviluppato in C/PSPSDK.  

Caratteristiche:  
- Gameplay ispirato a Tricky Towers  
- Compatibile con PSP 1000/2000/3000 ma su PSP 1000 la simulazione della fisica potrebbe subire rallentamenti

E' stato testao su psp 3004, psvita con adrenaline e ppsspp
